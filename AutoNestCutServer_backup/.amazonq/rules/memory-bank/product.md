# AutoNestCut License Server - Product Overview

## Purpose and Value Proposition
AutoNestCut License Server is a Node.js-based authentication and licensing service that manages access control for the AutoNestCut SketchUp extension. It provides secure license validation, user authentication, and email notifications for a cutting optimization plugin.

## Key Features and Capabilities

### License Management
- JWT-based license token generation using RSA256 encryption
- Secure license validation for SketchUp extension users
- Integration with Supabase database for license storage and management
- Real-time license status verification

### Authentication System
- RSA public/private key cryptographic authentication
- Secure token-based access control
- Environment-based configuration management
- Production-ready security implementation

### Email Integration
- Automated email notifications via Resend API
- License activation and renewal notifications
- User communication system for license-related events

### Database Integration
- Supabase backend integration for user and license data
- Service role authentication for secure database operations
- Scalable cloud-based data management

## Target Users and Use Cases

### Primary Users
- SketchUp extension developers requiring license management
- CAD professionals using cutting optimization tools
- Woodworking and manufacturing businesses needing automated nesting solutions

### Use Cases
- **License Activation**: Validate and activate new user licenses
- **Access Control**: Ensure only licensed users can access premium features
- **User Management**: Track license usage and user activity
- **Automated Notifications**: Send license-related emails to users
- **Secure Communication**: Provide encrypted communication between SketchUp extension and server

## Business Value
- Enables monetization of SketchUp extensions through secure licensing
- Provides scalable user management for growing customer base
- Ensures software piracy protection through cryptographic security
- Automates customer communication and license management workflows
